# bazis-author 2.3.0

Requires Bazis 2.3 (Django 6.1, FastAPI 0.142) and bazis-users 2.3.

- With bazis-users 2.3 the user context is reset after every request handled by
  `UserRequestMiddleware`: under a WSGI server with worker threads, a record saved by an
  anonymous request (or a request of another user) in the same thread could get the author
  of the previous request.
- Test that a client cannot set `author` or `author_updated` through relationships.
- Dependencies: `bazis>=2.3.0`, `bazis-users>=2.3.0`.
- CI runs the tests on Python 3.12–3.14 and with the lowest allowed dependency versions;
  releases are made with the Release workflow (see `CLAUDE.md`).
