# bazis-author 2.4.2

Requires Bazis 2.4.

## Fixes

- The admin changelist of an `AuthorAdminMixin` model works with Django 6.1: the
  autocomplete filter by author (django-admin-autocomplete-filter 0.7) took its choices
  from the descriptor of the field, whose `get_queryset()` needs an instance since
  Django 6.1, and the page failed with `TypeError`. The filter is now
  `bazis.contrib.author.admin_abstract.AuthorFilter`, which takes the users of the related
  model; the parameter of the changelist (`?author=<id>`) is unchanged.
