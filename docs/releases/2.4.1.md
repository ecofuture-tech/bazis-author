# bazis-author 2.4.1

Requires Bazis 2.4. Documentation only; the code is the one of 2.4.0.

## Documentation

- The guide (`bazis/contrib/author/AGENTS.md`) and the manifest say that `author` and
  `author_updated` have no `verbose_name` (the schemas title them `author` and
  `author updated`) and how a route gives them a title without a migration
  (`SchemaField(source='author', title=_('Author'))`; tested with the sample
  `DependentEntityRouteSet`).
