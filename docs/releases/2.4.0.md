# bazis-author 2.4.0

Requires Bazis 2.4.

## Tools and AI agents

- The package ships `AGENTS.md` (setup, how the author fields are filled, rules) and
  `bazis_manifest.toml` for tools and AI agents (see `docs/agents.md` of Bazis).
- New system check `author.W001` (`manage.py bazis_doctor`): a JSON:API route of an
  `AuthorMixin` model lets clients set `author` or `author_updated` (the route does not
  inherit `AuthorRouteMixin` and the fields are in its create or update schema). The check
  is registered by the app: add `bazis.contrib.author` to `BS_INSTALLED_APPS`.
- Dependencies: `bazis>=2.4.0`.
